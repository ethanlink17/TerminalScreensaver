################################
# Terminal Screensaver project #
################################

Developed by Ethan Link (Github @ ethanlink17) for fun
Began in Fall 2025

To build: 
`make all` (will make the directories you need as well, though if you want to do that separately you can run `make directories`)

To clean:
`make clean` (Deletes any files made along the way)
or 
`make cleaner` (Deletes the temporary directories as well)

Executable will be placed in bin/ directory. Can run using
`./bin/aquarium.c`

Only tested in Bash Terminal in Linux Mint
Does not work in Windows (at least yet), due to use of ioctl to get size of terminal window. I'm assuming `tput` wouldn't work either, but I haven't looked into it.

obj/ holds .o files generated by gcc during compilation
dep/ holds .d files for faster compilation using dependency files
src/ holds .c source files
inc/ holds .h include files
exmpl/ holds a proof of concept of this project, that I couldn't get myself to delete
